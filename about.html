About Dynamic Data Viewer

Dynamic Data Viewer is an interactive web application designed to fetch, display, and manage real-time dynamic data feeds asynchronously using modern Vanilla JavaScript (ES6+) and public REST APIs.

Core Technical Features

⚡ Dynamic Data & Async API

Fetches live API data feeds with interactive loading skeletons and error handling.

🔍 Debounced Search & Sorting

Client-side debounced search input, category filters, and price sorting.

💾 LocalStorage Cart Workflow

Shopping cart state management, quantity adjustment, subtotal calculation, and instant alerts.

🎨 Dark Mode & Responsive UI

Tailwind CSS styled with auto-responsive mobile hamburger navigation and theme toggle.
