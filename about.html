About Dynamic Data Viewer

Dynamic Data Viewer is an interactive web application designed to fetch, display, and manage real-time dynamic data feeds asynchronously using modern Vanilla JavaScript (ES6+) and public REST APIs.

Core Technical Features

⚡ Dynamic Data & Custom Fetch Wrapper

Fetches live API feeds with custom retry logic, interactive loading skeletons, and error boundary handling.

🔍 Debounced Search & Sorting

Client-side debounced search input (300ms delay), dynamic category filters, and price sorting.

💾 Caching & Pagination Workflow

SessionStorage API data caching, client-side pagination (8 items/page), and LocalStorage cart state management.

🎨 Dark Mode & Event Delegation

Tailwind CSS styled with auto-responsive mobile hamburger navigation, theme toggle, and event delegation.
