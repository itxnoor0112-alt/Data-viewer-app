About Dynamic Data Viewer

Dynamic Data Viewer is an interactive web application designed to fetch, display, and manage real-time dynamic data feeds asynchronously using modern Vanilla JavaScript (ES6+) and public REST APIs.

Core Technical Features

⚡ Dynamic Data & Async API

Fetches live API data feeds with interactive loading skeletons and error boundary handlers.

🔍 Debounced Search & Sorting

Client-side debounced search input, category filters, and price-based sorting (Low to High / High to Low).

💾 LocalStorage Persistence

Manages shopping cart state, product quantities, and provides instant "Added to cart" feedback messaging.

🎨 Dark Mode & Responsive Layout

Designed with Tailwind CSS featuring dynamic dark/light mode switching and multi-page routing.
